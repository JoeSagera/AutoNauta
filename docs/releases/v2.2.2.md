# AutoNauta 2.2.2 beta — reconexión y contador corregidos

La versión 2.2.1 podía quedarse esperando una redirección al portal y no enviar el login cuando Nauta no abría un popup. La 2.2.2 comprueba también Internet directo por el router y, si las comprobaciones fallan, reconoce el formulario HTTPS de Nauta para reconectar. Conserva AUTO/MAN y evita repetir el login cuando el router ya tiene Internet.

También corrige el contador de Nauta Hogar: reconoce la página conectada, utiliza su CSRF y envía el contexto completo de sesión. «Usuario ya conectado» se trata como espera temporal y no desactiva permanentemente el login automático.

## Descargar y actualizar

Descarga **AutoNauta-v2.2.2-windows-x64.zip**, extráelo y abre `AutoNauta.exe`. Para actualizar, cierra la versión anterior mediante **Salir** antes de reemplazarla. Tu cuenta y preferencias se conservan en la carpeta local de Windows. No necesita VPN ni administrador.

Si ya iniciaste sesión en Chrome y el contador muestra «No disponible», pulsa **Actualizar** en la página conectada de Nauta y guárdala como HTML. En el menú de clic derecho del LED, elige **Vincular contador del navegador…** y selecciona ese archivo. AutoNauta confirma la cuenta y el tiempo con el servidor antes de guardarlo. Esa página contiene datos privados de tu sesión: no la compartas.

## Validación y alcance

76 pruebas correctas, incluida caída sin popup → login → Internet → contador, y fallo de VPN con Internet físico → ningún login. La revisión de interfaz pasó. La consulta corregida obtuvo un tiempo válido en Nauta Hogar y el usuario confirmó que aparece en el LED.

Sigue siendo **beta**: observar una recuperación completa durante la siguiente caída real está pendiente. No repara una línea ADSL sin señal. Mantiene las optimizaciones de segundo plano y añade las comprobaciones físicas solo después de fallos de Internet.

Windows 11 x64 fue el sistema probado; Windows 10/11 x64 con .NET Framework son los sistemas previstos. No cambia rutas ni desconecta tu VPN. Las restricciones del cliente VPN o del cortafuegos pueden impedir acceder al portal.

El ZIP contiene programa, guía y sumas SHA-256. No contiene cuentas, contraseñas, sesiones, HTML privados ni perfiles VPN. Los datos de cada usuario se guardan cifrados en `%LOCALAPPDATA%\AutoNauta`. El ejecutable no está firmado digitalmente; las sumas permiten comprobar integridad, no sustituyen una firma.
