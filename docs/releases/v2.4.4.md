# AutoNauta 2.4.4 beta — segunda revisión de seguridad y fiabilidad

Actualización recomendada desde **2.4.3 y anteriores**, con las correcciones detectadas por una segunda revisión independiente con **GPT-6.1 Sol en razonamiento Max**.

## Correcciones

- Una consulta informativa rechazada con HTTP401/403 deja de repetir usuario y contraseña cada minuto o al pulsar «Comprobar ahora». La vigilancia y el login conservan su funcionamiento. Revisa y guarda la cuenta, o vincula una sesión válida, para reabrir la consulta del contador.
- El análisis de HTML tiene un presupuesto total por documento, además del timeout individual de cada regex. Una carga sintética que tardaba unos 37–39 segundos en 2.4.3 se rechaza en alrededor de un segundo en las pruebas locales, sin ejecutar el HTML ni enviar login.
- Una sesión AUTO descartada antes de confirmar Internet deja de sumar un AUTO efectivo cuando la conexión se recupera de forma independiente después.

El subagente no confirmó fallas críticas o altas dentro del alcance revisado. Los tres defectos se reprodujeron sin red y se volvieron a comprobar después de corregirlos. No se probaron reintentos con una cuenta real ni ataques al servidor.

## Descargar y actualizar

Descarga **AutoNauta-v2.4.4-windows-x64.zip**, extráelo y abre `AutoNauta.exe`. No necesita instalador, VPN ni administrador. Para actualizar, cierra la versión anterior con **Salir** y sustituye el ejecutable. Cuenta y preferencias se conservan; las estadísticas de la ejecución se reinician al reabrir.

El ZIP incluye únicamente programa, guía, licencia MIT y sumas SHA256. No incluye configuración, cuentas, sesiones o HTML privados. Los enlaces «Source code» son las fuentes, no el programa preparado.

## Validación y límites

**98 pruebas correctas**, más reproducciones separadas del revisor, interfaz a 100 %, 150 % y 200 % y verificación del paquete. Detalle de hallazgos y límites: [informe de Sol](https://github.com/JoeSagera/AutoNauta/blob/main/docs/REVISION-SOL61-2.4.4.md).

Conserva el LED lateral, la barra compacta, superposición, contador y reconexión de las versiones anteriores. Probado en Windows 11 x64, requiere .NET Framework 4.8; Windows 10 no se validó con esta entrega. No repara una línea ADSL sin señal ni se inicia automáticamente con Windows.

Sigue siendo beta y el ejecutable no está firmado digitalmente. Comprueba el SHA256 publicado; las sumas comprueban integridad, no sustituyen una firma. AutoNauta no está afiliado a ETECSA ni a proveedores de VPN.
