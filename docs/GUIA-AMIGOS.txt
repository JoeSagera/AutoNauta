AUTONAUTA 2.4.2 — BETA PARA WINDOWS X64

Programa portátil para vigilar Nauta Hogar y volver a iniciar sesión cuando
el portal confirma que se necesita acceso. No requiere instalador.

EMPEZAR
1. Extrae el ZIP completo a una carpeta de tu computadora.
2. Abre AutoNauta.exe. No necesita permisos de administrador.
3. Escribe tu propia cuenta completa de navegación Nauta y contraseña.
4. Pulsa Guardar cuenta y después Iniciar en la fila Vigilancia.
5. Minimiza la ventana o ciérrala con la X: el LED y la vigilancia siguen activos.
   Para terminar el programa, elige Salir.

COMPATIBILIDAD
La versión actual se probó en Windows 11 x64, con Nauta Hogar.
Usa .NET Framework; Windows 10/11 x64 son los sistemas previstos.
No requiere VPN. Verifica Internet por la salida que usa Windows y accede
al portal Nauta por la interfaz del router. No cambia las rutas del sistema.

EL LED
Verde: conexión a Internet confirmada.
Amarillo: reconexión, espera de Internet o acción pendiente.
Rojo: error del portal, de la cuenta o del acceso.
Gris: pausa o espera de confirmación.

En verde, el LED se esconde en el borde lateral más cercano y deja una
pequeña muesca. Pasa el mouse por ella para ver el tiempo y las velocidades;
al retirar el mouse se esconde de nuevo. En amarillo, rojo o gris vuelve
el LED completo a la posición donde lo dejaste.
La chincheta mantiene la barra abierta. Arrastra el LED para moverlo.
Cuando está fijada y retiras el mouse, quedan solo LED, horas y velocidades;
AUTO/MAN y la chincheta reaparecen al pasar por encima.
El indicador recupera su prioridad cuando otra ventana lo tapa, sin quitarle
el foco a la aplicación activa. En juegos, usa ventana sin bordes si el modo
pantalla completa impide que Windows muestre el indicador encima.
Doble clic abre la ventana. Si necesitas restaurar el indicador, haz clic
derecho en el icono de AutoNauta junto al reloj y elige Recuperar LED.

AUTO permite iniciar sesión cuando Nauta confirma que pide acceso.
MAN mantiene la vigilancia, pero no inicia sesión automáticamente.
Pausar detiene las comprobaciones; no cierra una sesión Nauta existente.

TIEMPO Y VELOCIDADES
Si la sesión se inició desde Chrome, pulsa Actualizar en la página de Nauta,
guárdala como HTML y elige Vincular contador del navegador en el menú de
clic derecho del LED. Selecciona ese HTML para consultar el tiempo actual.
La página contiene datos privados de tu sesión: no la compartas.
También obtiene el contador después de un login automático. Se actualiza
cada minuto. No cierra ni repite tu login para conseguirlo.
Las velocidades son el tráfico de tu computadora en bits por segundo;
no son un test de velocidad ni incluyen los demás equipos del router.

DATOS PERSONALES
Este paquete no contiene ninguna cuenta, contraseña, sesión o configuración.
Cada persona introduce sus propios datos, que se guardan cifrados para su
usuario de Windows en %LOCALAPPDATA%\AutoNauta. No compartas esa carpeta.
Puedes usar Eliminar cuenta en la aplicación para borrar los datos guardados.

ALCANCE DE LA BETA
Se comprobaron 92 pruebas locales, la interfaz y la consulta del contador
en una sesión real de Nauta Hogar. La reconexión completa durante una nueva
caída real de Nauta todavía requiere validación de campo.
No repara una línea ADSL sin señal. No arranca automáticamente con Windows.
El programa no está afiliado a ETECSA ni a Proton.

CONTADORES Y ACTIVIDAD
Esta ejecución muestra caídas confirmadas, recuperaciones de Internet,
intentos AUTO y AUTO efectivos. Solo es efectivo un login que Nauta
confirma y después recupera Internet. Una caída se cuenta una sola vez;
los cambios de color y las pausas no multiplican los números. Se mantienen
al pausar/reanudar y empiezan de cero al cerrar y abrir el programa.

Copiar actividad copia las últimas 50 entradas mostradas. También puedes
seleccionar filas y pulsar Ctrl+C, o Ctrl+A para seleccionar todas. Doble
clic abre el detalle completo, donde puedes seleccionar parte del texto.
El menú de clic derecho permite Ver registro completo para consultar el
archivo guardado, incluido lo anterior a esta apertura.

ACTUALIZAR
Cierra AutoNauta mediante Salir y reemplaza el ejecutable por el nuevo.
Tus datos y preferencias se conservan fuera de la carpeta del programa.
